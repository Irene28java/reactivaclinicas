¿Funciona con cualquier web? ▾

Instalación paso a paso
1
Descarga e instala el servidor
Ejecuta este comando en tu terminal para instalar el backend de ReActiva:
cd backend npm install cp .env.example .env npm start
2
Configura tus variables de entorno
Abre el archivo .env y añade tus credenciales de Instagram y Messenger:
INSTAGRAM_TOKEN=tu_token_aqui MESSENGER_PAGE_TOKEN=tu_token_aqui EMAIL_USER=tu@clinica.com EMAIL_PASS=tu_contraseña
3
Añade el widget a tu web
Pega este snippet antes del cierre de </body> en tu web:
<script src="https://cdn.reactiva.app/widget.js" data-key="TU_API_KEY"></script>
4
Conecta tus redes en el panel
Accede a tu panel, ve a Configuración → Canales y conecta Instagram DM, Messenger y Email con un solo clic. El bot arranca solo en menos de 60 segundos.
